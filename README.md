# DevOps Capstone Project - Customer Accounts Microservice

![Build Status](https://github.com/Dractum07/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)

A Customer Accounts microservice with a RESTful API (create, list, read, update, delete), automated CI with GitHub Actions, security headers and CORS, Docker containerization and Kubernetes deployment.

## Project Name
DevOps Capstone Project - Customer Accounts Service

## Contents
* `setup.cfg` - nosetests, coverage, Flake8 and Pylint configuration
* `user-story.md` - user story template
* `.github/workflows/ci-build.yaml` - continuous integration workflow
* `Dockerfile` - container image definition
